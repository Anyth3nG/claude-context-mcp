# Deployment bundle only — keep this list minimal.
#
# Lambda allows 250MB unzipped and 52,428,800 bytes (50MiB) for a direct zip
# upload. The zipped figure is the one that binds, and .github/workflows/deploy.yml
# guards both. Two choices do most of the work of staying under them:
#   - no chromadb: the store is DynamoDB, and since the rollback path retired
#     there is no reason to ship a second backend's client. Removing it took 16
#     transitive packages with it — grpcio, protobuf, the opentelemetry stack,
#     PyYAML, orjson — and about 30MB unzipped.
#   - no voyageai: the SDK pulls pillow, tokenizers, hf_xet and aiohttp
#     (~90MB) for features this project never touches. shared/store.py calls
#     the same REST endpoint directly with httpx.
#
# Install for arm64 (Graviton), matching the function's architecture:
#   pip install --target build --platform manylinux2014_aarch64 \
#       --python-version 3.13 --implementation cp --only-binary=:all: \
#       -r requirements-lambda.txt
#
# Do NOT strip .dist-info directories from the bundle to save space —
# importlib.metadata reads them at runtime and imports fail without them.
httpx
numpy
mcp
mangum

# Cognito access-token verification.
PyJWT
# RS256 needs it, and PyJWT does not declare it — it is an extra. This used to
# arrive transitively through chromadb-client and was written down as such;
# dropping that package made a security-critical dependency depend on whatever
# else happened to pull it in. Named here so it is chosen rather than inherited.
cryptography

# boto3, which the Lambda runtime ALSO provides — but the runtime's copy predates
# DynamoDB's SearchVectors API and therefore cannot do vector search. That failed
# in production and nowhere else: reads and writes use Query and PutItem, which
# have existed for years, so the store looked healthy while search_context alone
# raised "'DynamoDB' object has no attribute 'search_vectors'". Local testing
# could not catch it, having installed a current boto3 in the dev venv.
#
# ~35MB unzipped, almost all of it botocore's service models — now the largest
# thing in the bundle by a wide margin.
boto3
